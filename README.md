# 📦 Supply Chain Data Analysis

## 📊 Project Overview

This project focuses on analyzing supply chain operations to identify delivery delays, performance bottlenecks, and key operational trends.

The analysis helps in understanding how different factors like shipping mode, region, and customer segment impact delivery performance.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Jupyter Notebook

---

## 📁 Dataset

The dataset contains information about:

* Orders & shipping details
* Delivery delays
* Customer segments
* Regions & departments
* Order status

---

## 📈 Analysis Performed

* Delay analysis across different regions
* Shipping mode impact on delivery time
* Customer segment behavior analysis
* Order status and delay correlation
* Factor-wise performance breakdown
